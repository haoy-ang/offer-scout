本文件是真实招聘岗位详情页的整理版。本批共 15 条，全部位于重庆。

## 第一档 · Java 后端开发（主力目标）

### JD-01 java 开发工程师（应届生友好）

基本信息：4.5–8 千 / 月；重庆-南岸区；在校生 / 应届生；本科；全职。

岗位职责
1. 负责或参与微服务架构下业务模块的设计、开发、测试与运维。
2. 编写高质量、可复用、易维护的 Java 代码，并保证性能与稳定性。
3. 参与技术方案讨论、代码审查，持续优化系统架构与开发流程。
4. 分析与解决线上技术问题，保障系统 7x24 小时稳定运行。
5. 编写和维护清晰的技术文档。

任职要求
1. 基础必备：计算机相关专业本科及以上，数据结构、算法、网络基础扎实。
2. 技术潜力：熟练掌握 Java 核心语法及特性，理解面向对象、集合、多线程；对 Spring Boot、MyBatis 有了解或项目经验。
3. 实践能力：在课程设计、个人项目、实习或竞赛中展现出优秀的编码和解决问题能力。
4. 个人素质：技术热情、学习能力、逻辑思维和团队协作精神。

简历关键词：Java、Spring Boot、MyBatis、集合、多线程、微服务、代码审查、线上问题排查。
参考价值：本批中门槛最贴合 2027 届本科的一条，要求与校招主流口径一致。

### JD-02 java 开发工程师（要求偏高，冲刺型）

基本信息：5 千–1 万 / 月；重庆-两江新区；1 年；本科；全职。

岗位职责
1. 负责核心业务系统的架构设计与开发，基于 Spring Cloud 等微服务框架构建高可用、高性能系统。
2. 独立完成微服务模块的设计、开发、单元测试及部署。
3. 持续优化系统架构，解决分布式场景下的高并发、数据一致性等复杂技术问题。
4. 需熟练使用 JSP、Servlet 等框架技术。
5. 加分项：参与前端核心模块开发与优化，提升前后端协作效率。

任职要求
1. Java 基础扎实：精通 Java，熟悉 JVM 原理、多线程、NIO、集合框架，有 JVM 调优经验。
2. 微服务生态：深入理解 Spring Boot、Spring Cloud（Gateway、OpenFeign、Nacos 等），熟悉分布式事务、消息中间件（RocketMQ / Kafka）及分布式缓存（Redis）。
3. 数据库能力：熟练 MySQL，具备 SQL 优化、数据库设计及分库分表经验，熟悉至少一种 NoSQL。
4. 工程化工具：熟练 Git、Maven / Gradle、Docker、Kubernetes，熟悉 Linux 环境及 Shell 脚本。
5. 加分项：前端精通，熟悉 Vue3 / React，能独立完成复杂前端页面与状态管理（Pinia / Redux），了解 Webpack / Vite 与前端性能优化。

其他信息：项目交付需出差，全国各地。

简历关键词：JVM 调优、NIO、Spring Cloud、Nacos、OpenFeign、分布式事务、RocketMQ、Kafka、分库分表、Docker、Kubernetes。
参考价值：标注「1 年经验」但实际要求接近 2–3 年，在本批中属于门槛最高的一条。
