# Java 后端岗位 JD 样本（示例素材）

> 本文件是跑通 RAG 链路的示例素材，请替换成你真实投递过的岗位 JD。
> 拿真实 JD 做知识库，AI 才能针对"你要投的岗位"给建议。

---

## 样本一：后端开发工程师（2027 届校招）

**岗位职责**
1. 参与公司核心业务系统的后端设计与开发
2. 编写高质量、可维护的代码，参与代码评审
3. 参与系统性能优化与线上问题排查

**任职要求**
1. 2027 届本科及以上学历，计算机相关专业
2. 扎实的 Java 基础：集合、并发、JVM 有基本认知
3. 熟悉 Spring / Spring Boot / MyBatis 等主流框架
4. 熟悉 MySQL，了解索引原理和常见优化手段
5. 了解 Redis，能说清缓存的使用场景与常见问题
6. 有良好的编码习惯和 Git 协作经验

**加分项**
- 有完整的项目经历，能讲清楚技术选型理由
- 了解消息队列（Kafka / RocketMQ）
- 有实习经历或开源贡献
- 了解 AI 应用开发（大模型接入、RAG、Agent）

**面试典型考点**
- 一面偏基础：Java 集合与并发、MySQL 索引、Redis 缓存问题
- 二面偏项目：为什么这么选型、遇到的最难的问题、如果重做会怎么改
- HR 面：职业规划、为什么选这个岗位、抗压能力

## 样本二：Java 后端开发（3 年经验）

**任职要求**
1. 3 年以上 Java 后端开发经验，有高并发系统经验
2. 精通 JVM 调优，能定位内存泄漏、CPU 飙高等线上问题
3. 熟悉分布式：服务治理、限流熔断、分布式事务
4. 熟悉 Kafka / RocketMQ，理解消息可靠性投递
5. 有分库分表、读写分离的实践经验

**考察重点**
- 线上问题排查思路（不比谁背得多，比排查路径）
- 系统设计能力（给场景，让你画架构）
- 对"为什么"的追问很深，答不到原理就会被追穿

## 样本三：后端开发实习生

**任职要求**
1. 在读本科 / 研究生，能保证每周 4 天以上
2. 掌握 Java 基础语法，了解面向对象
3. 用过 Spring Boot 写过简单接口（有课程设计 / 个人项目即可）
4. 会用 MySQL 写基本的增删改查

**实习面试特点**
- 门槛比校招低，但更看**动手能力**和**学习意愿**
- 常问："你项目里遇到什么问题、怎么解决的"
- 会现场让你写一段简单代码（比如单例、字符串处理）

**实习转正路径（重点）**
- 大厂暑期实习是校招最稳的通道，转正率普遍高于直接秋招
- 2027 届应该在 **2026 年 3-5 月**投递 2026 暑期实习
- 实习期间最重要的是"把事做完 + 主动同步"，而不是炫技

## 简历筛选的常见红线

1. 项目描述全是"实现了增删改查"，看不出技术含量
2. 只写"使用了 XX 技术"，不写"解决了什么问题、效果如何"
3. 技能清单堆砌关键词，一被追问就答不上
4. 时间线有空白或前后矛盾
